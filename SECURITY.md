# Security policy

This repository is a catalog. It does not redistribute or execute the listed plugins.

## Report a catalog problem

Use [private vulnerability reporting](https://github.com/NOirBRight/dsh-plugins/security/advisories/new) for a malicious entry, compromised release, exposed credential, or disclosure that could put users at immediate risk. Do not open a public issue containing secrets or exploitation details.

Use a normal issue for stale versions, broken links, classification mistakes, or documentation corrections.

A credible urgent report may move an entry to `quarantined` before the underlying plugin investigation finishes. Quarantine removes the entry from normal recommendation without erasing its audit record.

## Plugin vulnerabilities

Report implementation vulnerabilities to the affected plugin repository. The catalog's inclusion and disclosure fields are not a security review, certification, warranty, or endorsement.
